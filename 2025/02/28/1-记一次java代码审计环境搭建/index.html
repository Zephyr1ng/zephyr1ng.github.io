1.记一次java代码审计环境搭建

创建于 2025-02-28 更新于 2025-03-06

前情提要：

学习自深情哥微信公众号文章~
https://mp.weixin.qq.com/s/k6j4QJuwmJAeZQAiLquUaA
以下主要是一些复现以及自己搭建遇到的问题~

源码来源：

https://gitee.com/zj1983/zz

搭建流程：

1.gitee上下载下来之后，idea打开

打开之后，idea右下角会自己加载Maven
然后就是如果resources不是资源根目录的话要设置为资源根目录

选中文件夹，右键选中之后->将目录标记为->资源根目录
我的加载完之后就是，所以就不修改了

2.然后打开phpStudy，启动mysql8服务(没有的话下载一个)

3.然后就是命令行连接mysq，创建z数据库，然后导入数据库文件

不报错就是正常执行了，下面这就是成功导入sql文件

tips：

这里你导入的sql文件的路径是不能包含的中午的，否则mysql会提示无法打开

4.然后就是修改数据的配置文件相关信息

5.最后就是设置tomcat环境

部署tomcat

如果本机上之前没用过tomcat的话，官网下载一个，然后解压之后，配置tomcat所在目录

然后就是部署工件

点+选择工件会自己弹出可以加载的
然后记得修改应用程序上下文的内容（如上图）

修改端口

不要和抓包的端口冲突

最后点击应用即可

6.最后启动tomcat即可成功启动

登录即可

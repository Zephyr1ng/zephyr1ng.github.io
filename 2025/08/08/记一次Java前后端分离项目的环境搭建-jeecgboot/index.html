https://github.com/jeecgboot/JeecgBoot/releases（我这里最新版是3.8.2）

https://d10.injdk.cn/openjdk/openjdk/

4.访问接口文档

三.前端-npm搭建

后端搭完了，接下来来搭前端，为了审代码更简洁明了一点

用vscode打开下载源码中的jeecgboot-vue3目录

1.下载前端依赖

然后在vscode中执行命令pnpm i 或者双击 pinstall

如果这里vs中没有npm脚本，参考文章：https://www.cnblogs.com/weipicun/p/16694552.html

如果运行显示没有pnpm命令，参考文章：https://www.pnpm.cn/installation，

这里很坑的一点就是我在下载的时候单纯使用npm install -g pnpm是下载不下来的，一直报错

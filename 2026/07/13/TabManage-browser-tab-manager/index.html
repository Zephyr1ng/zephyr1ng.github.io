TabManage：让浏览器标签页重新变得有序

日常工作中，我们常常需要同时打开文档、代码仓库、邮件、视频、搜索页面等大量标签页，浏览器顶部栏被挤得密密麻麻，想找回之前打开的某个页面也变得非常困难。

于是我开发了 TabManage（页序），一款适用于 Chrome 和 Edge 的轻量级标签页管理插件。

项目地址：https://github.com/Zephyr1ng/TabManage

主要功能

  • 自动分类 — 按用途自动将标签页分组：工作、开发、文档、沟通、影音
  • 自定义规则 — 可重命名分类，自定义域名归属规则
  • 快速搜索 — 按标题或网站名查找并切换标签页
  • 保持整洁 — 自动折叠未使用的标签组，减少顶部栏杂乱
  • 清理重复页面 — 一键关闭重复 URL
  • 恢复页面 — 显示并恢复最近关闭的 15 个标签页

使用方法

  1. 下载并解压项目
  2. 打开 chrome://extensions/（Chrome）或 edge://extensions/（Edge）
  3. 开启开发者模式，点击「加载已解压的扩展程序」
  4. 选择插件目录，点击工具栏的「页序」图标即可使用

打开侧边栏后，插件会自动整理当前窗口的标签页。也可以点击「立即整理」手动触发，设置中可编辑分类名称和域名规则。

隐私说明

无需注册账号，不读取网页内容，不上传浏览数据。分类规则和设置均存储在浏览器本地。
